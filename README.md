# Tarta de 3 pisos · PWA

Aplicación web progresiva de la receta de tarta de tres pisos de bizcocho de yogur griego.

## Funciones
- Receta completa paso a paso.
- Bizcochos de 20 × 7 cm, 15 × 6 cm y 10 × 4 cm.
- Rellenos de Nutella, Kinder Bueno y chocolate blanco.
- Cobertura de nata estabilizada en morado, rosa y azul.
- Tiempos orientativos de horneado por tamaño.
- Lista de compra dinámica según el número de tartas.
- Seguimiento de pasos mediante casillas persistentes.
- Instalable como PWA y preparada para uso offline.

## GitHub Pages
Publicar desde la rama `main` y la carpeta `/ (root)`.

## iPhone / iPad
Abrir la URL de GitHub Pages en Safari → Compartir → Añadir a pantalla de inicio.
